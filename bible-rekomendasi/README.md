# Bible Rekomendasi - Tim Meja AK Talent

Rekomendasi bible untuk 3 karakter: **Arissa (Hati), Kirana Harunika (Otak), Musthzen (Drive)** — saling komplementer di meja diskusi.

## Versi tim perusahaan: AK Productions × AK Talent

Paket sinkron yang mempertahankan Bible asli sambil menambahkan peran perusahaan, portofolio skill, relasi khusus dengan pemilik, dan memori kolaborasi ada di [`ak-productions-team/`](./ak-productions-team/). Untuk memuat semua field sekaligus, gunakan **Impor dossier karakter** dan pilih file JSON di folder tersebut. Bible rekomendasi asli di folder ini tidak diubah.

## Isi Folder
- `01-Arissa-bible.txt` — bible lengkap Arissa (6130 karakter)
- `01-Arissa-bible.json` — siap impor (nama + personality + shortBio + greeting + bible)
- `02-Kirana-Harunika-bible.txt` / `.json` — Kirana (6491 karakter)
- `03-Musthzen-bible.txt` / `.json` — Musthzen (6692 karakter)

Semua di bawah limit: bible max 24.000, personality max 8.000, shortBio 120, greeting 1000.

## Cara Impor ke Aira / AK Talent

### Opsi A: Impor file
- Untuk Bible asli di folder ini, gunakan **📖 Bible peran → Impor berkas**; JSON lama juga mengisi nama/kepribadian/status/greeting.
- Untuk dossier tim yang menyatukan Bible, skill, peran, dan memori Tim 1, gunakan folder [`ak-productions-team/`](./ak-productions-team/) lalu klik **Impor dossier karakter → Pilih JSON**. Tinjau hasil dan simpan perubahan.

### Opsi B: Copy-paste manual
1. Buat karakter baru, isi **Nama**, **Status singkat**, **Kepribadian & latar belakang** (copy dari bagian `personality` di json).
2. Copy seluruh isi `.txt` ke kolom **📖 Bible peran**.
3. Isi **Pesan pembuka** dari `greeting`, simpan.

## Tips Pakai di Meja Diskusi
- Arissa buka vibe → Kirana bikin struktur → Musthzen eksekusi. Urutan ini bikin brainstorm gak muter.
- Di setting Meja, masukin ketiganya dalam 1 room, kasih judul project yang jelas biar Character ID mereka kepake maksimal.
- Kalau mau sesuaikan, edit aja bagian LATAR & GAYA BICARA di bible — jangan hapus bagian ATURAN PERAN biar tetap natural.
